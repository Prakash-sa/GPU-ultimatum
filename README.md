## Building locally

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
mkdocs serve          # http://127.0.0.1:8000
```

## Running the LeetGPU solutions

```bash
pip install torch triton
python docs/leetgpu/05_softmax.py                     # tests + benchmark on a CUDA GPU
PROFILE=1 python docs/leetgpu/05_softmax.py           # + torch.profiler table and trace
TRITON_INTERPRET=1 python docs/leetgpu/05_softmax.py  # no GPU: kernels run on the CPU

python tests/cuda/run_tests.py --gpu 05_softmax       # CUDA version: build with nvcc, test on the GPU
```

Without a GPU, the CUDA versions are tested in Docker: `tests/cuda/run_tests.py` runs them
on the CPU through `tests/cuda/cuda_cpu.h`, and `tests/cuda/nvcc_check.sh` compiles them
with the real nvcc for sm_75/80/90. See
[Running the CUDA versions](docs/leetgpu/index.md#running-the-cuda-versions).

## Updating the Before GPU Engineering notebook

`docs/notes/before-gpu/` is generated from
[BEFORE-GPU-ENGINEERING](https://github.com/BEFORE-GPU-ENGINEERING/BEFORE-GPU-ENGINEERING)
(MIT, © Ranjan Yadav). Each chapter keeps its upstream HTML (text, highlights, diagrams)
inside a Markdown page, so it uses the site theme; the script also writes the nav block in
`mkdocs.yml` and redirects from the old `docs/before-gpu/` URLs. Don't edit the generated
pages by hand. To pull new chapters:

```bash
git clone --depth 1 https://github.com/BEFORE-GPU-ENGINEERING/BEFORE-GPU-ENGINEERING /tmp/bge
python scripts/import_before_gpu.py /tmp/bge
```

## Publishing to GitHub Pages

`.github/workflows/pages.yml` builds the site with `mkdocs build --strict` and
deploys it on every push to `main`. You only need to turn it on once: in the
repository on GitHub, go to **Settings → Pages → Build and deployment → Source**
and choose **GitHub Actions**.
